# Имидж Авто

Статический сайт автосервиса в Калининграде. Главная страница — `index.html`.
Сайт можно открыть локально без сборки.

## Структура

- `website/css/` — стили сайта.
- `website/js/` — общая логика и сторонние библиотеки.
- `media/` и `website/images/` — изображения.
- `contacts/index.html` — контакты и карта проезда.
- `price/index.html` — прайс-лист.
- `_tools/` — локальные скрипты проверки и обслуживания.
- `_archive/` — архивные материалы.
